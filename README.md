## 🔥 Featured Projects

### 🪑 Smart Posture Monitor
**Computer Vision & Machine Learning Engineer**  
`Aug 2026 – Present`

A real-time sitting posture recognition system combining **YOLO-Pose** with classical Machine Learning.

**Highlights:**
- Built an end-to-end real-time posture recognition pipeline
- Extracted **6 upper-body keypoints** using YOLO-Pose
- Designed **12 raw geometric features (RAW12)**
- Developed a **personal calibration mechanism**
- Transformed raw features into **13 personalized relative features (REP13)**
- Evaluated models using **nested Leave-One-Person-Out** and grouped cross-validation
- Compared **SVM, XGBoost, Random Forest, and MLP**
- Selected a tuned **RBF-SVM**
- Achieved **0.909 Macro F1** and **91.9% accuracy on unseen subjects**

**Tech:**  
`Python` `YOLO-Pose` `OpenCV` `Scikit-learn` `SVM` `XGBoost`

🔗 [View Repository](https://github.com/QuangCanhCut/smart-posture-monitor)
